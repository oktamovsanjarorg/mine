# Features

SanjarBot provides a rich set of features divided into 22 core modules.

## Modules

1. **User Onboarding:** Seamless welcome and language selection.
2. **AI Chat:** Natural language interaction using LLMs.
3. **Reminders:** Schedule customized reminders via `/remind`.
4. **Settings:** Manage preferences using inline keyboards.
5. **Analytics:** View personal usage stats.
...

## Commands

- `/start` - Start the bot
- `/help` - Show help message
- `/settings` - Open settings menu
- `/remind <time> <text>` - Set a reminder

## Inline Buttons
All interactive menus use aiogram's `CallbackData` for robust type-safe callback handling.
